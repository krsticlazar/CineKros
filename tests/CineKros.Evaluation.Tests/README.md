# CineKros.Evaluation.Tests

Fixture tests for evaluation query-set loading, mode selection, filter compliance, parser comparisons, retrieval metrics, judgments, and report serialization. They use controlled examples and do not call Gemini or access the runtime database.

```powershell
dotnet test --project tests/CineKros.Evaluation.Tests/CineKros.Evaluation.Tests.csproj
```
